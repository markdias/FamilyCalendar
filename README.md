# FamilyCal

FamilyCal is a comprehensive family calendar application built with React Native + Expo, designed to help families coordinate schedules and events.

## Project Documentation

For development guidance and project specifications, please refer to the following documentation:

- [CLAUDE.md](./CLAUDE.md): Guidance for Claude Code and general project principles.
- [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md): Visual design system, colors, typography, and components.
- [FEATURES.md](./FEATURES.md): Feature specifications, data models, and Pro feature enforcement.
- [USER_FLOWS.md](./USER_FLOWS.md): User journeys, screen specifications, and navigation patterns.

## Getting Started

This repository currently contains the project's documentation and a basic Next.js structure for the web component.

To get started with the development environment:

```bash
npm install
npm run dev
```

## Tech Stack

- **Frontend**: React Native + Expo (Mobile), Next.js (Web)
- **Backend**: Supabase (Auth, Database, Storage)
- **Local Cache**: WatermelonDB / SQLite
- **Styling**: Tailwind CSS (Web), Nativewind (Mobile)
- **Language**: TypeScript
